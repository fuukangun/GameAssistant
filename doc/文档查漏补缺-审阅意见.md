## 二、遗留微调（均为可选，不阻塞开发）

### 1. 技术设计 11.4 验收样例未同步更新

需求文档 9.4 已扩展到 9 个边界场景，但技术设计 11.4 仍只有 5 个样例。建议补充：

| 样例 | 预期 |
|------|------|
| 冬28存档 + 任意天气 | 计划日期 = 次年春1，季末风险P0 |
| 多人存档 | 基础字段展示 + parseWarning `unsupported_multiplayer` |
| `uniqueIDForThisGame` 缺失 | 备注降级用路径关联 |
| 静态数据文件损坏 | 对应数据源标记不可用，建议降级 |

### 2. 多人存档检测逻辑未明确

需求 2.6 描述了降级策略，技术 3.5 矩阵也列了"多人存档必须不崩溃"，但解析模型中没有说明如何检测多人存档。星露谷多人存档的 XML 中有 `<farmhands>` 节点，建议在 3.4 或 3.6 中补充检测依据。

### 3. `configVersion` 迁移策略可补充

技术 9.2 提到"根据 configVersion 执行自动迁移"，但没有说明版本号规则（从1递增？还是语义化？）。建议补充一句：`configVersion` 为正整数，每次配置结构变更递增1，迁移按序执行。
