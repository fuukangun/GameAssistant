# Mac 应用提示“已损坏”的解决方案

## 问题原因
您的 App 在朋友的 Mac 上安装后提示“已损坏”，**并非文件真的损坏**，而是 macOS 的 **Gatekeeper 安全机制** 拦截了未经 Apple 官方公证（Notarization）的开发者应用。系统默认只信任来自 App Store 或经过签名的应用，因此会弹出该提示。

---

## 临时解决方法（按推荐顺序）

### 方法一：通过“隐私与安全性”设置放行（最推荐）
这是最安全、最规范的操作，无需关闭系统保护。

1. 打开 **“系统设置”** → **“隐私与安全性”**。
2. 滚动到页面下方的 **“安全性”** 区域，您会看到一条关于“游戏助手”被阻止的提示。
3. 点击提示旁边的 **“仍要打开”** 按钮，并输入管理员密码确认。
4. 之后再次尝试打开 App 即可。

---

### 方法二：使用终端命令移除“隔离属性”
如果方法一无效（或未出现“仍要打开”按钮），可以用终端移除系统给 App 添加的隔离标记。

1. 打开 **“终端”**（Terminal）。
2. 输入以下命令（注意末尾有一个空格）：
   ```bash
   xattr -cr 
   ```
3. 将 **“游戏助手.app”** 从“访达”（Finder）的“应用程序”文件夹中**直接拖拽到终端窗口**里，终端会自动补全应用路径（例如：`/Applications/游戏助手.app`）。
4. 按回车键执行命令。完成后，再尝试打开 App。

> **注意**：如果提示权限不足（Permission denied），请在命令前加上 `sudo` 并输入密码（密码不显示）：
> ```bash
> sudo xattr -cr 
> ```
> 然后将 App 拖入终端，回车执行。

---

### 方法三：启用“任何来源”选项（不推荐长期使用）
此方法会降低系统安全性，仅在临时测试时使用，用完后建议立刻恢复。

1. 在终端执行以下命令以开启“任何来源”：
   ```bash
   sudo spctl --master-disable
   ```
2. 输入管理员密码（屏幕上不会显示），然后回车。
3. 打开 **“系统设置”** → **“隐私与安全性”**，在“安全性”区域会多出 **“任何来源”** 选项，勾选它。
4. 现在您的 App 应该可以正常打开。
5. **问题解决后，强烈建议重新启用安全防护**，在终端执行：
   ```bash
   sudo spctl --master-enable
   ```
